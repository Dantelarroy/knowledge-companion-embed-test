# Elkanodata — embed test page

One static page, published to GitHub Pages, used to check that an embeddable
assistant loads from a public website on a domain other than the one serving it.

The page is Elkanodata's. It is not affiliated with, and does not represent, any
organisation whose material the assistant may cite.

**This repository contains the page and nothing else.** No application code, no
corpus, no configuration, no credentials, no conversations.

The assistant it points at runs on a laptop for the duration of a review and
answers only while that machine is on. It is not a deployment and has no service
agreement. When the review ends the page stops loading anything.
