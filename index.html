Elkanodata · entorno de pruebas

Prueba de incrustación del asistente de conocimiento

Demostración temporal. Esta página es de Elkanodata y sirve para verificar el snippet desde una web pública real. El asistente se sirve desde un portátil y sólo responde mientras ese equipo está encendido. No es un despliegue, no tiene acuerdo de servicio y desaparece al terminar la prueba.

Dos formas de verlo

Incrustado. El recuadro que aparece abajo a la derecha es el mismo componente que se instalaría en una web de cliente: una sola etiqueta <script>, sin framework y sin tocar el resto de la página.

Completo. La misma herramienta con su propia pantalla, con el catálogo de fuentes a la vista.

Abrir Knowledge Hub completo ↗

Mismo motor, mismo contenido y las mismas cuotas: cambia la superficie, no la respuesta. Se abre en una pestaña nueva porque el Hub, a propósito, no se deja incrustar en ninguna página — sólo el widget puede vivir dentro de otra web.

El snippet, tal cual

<script async
  src="https://dantes-macbook-pro.tail09f5c9.ts.net/v1/loader.js"
  data-kc-tenant="afi"></script>

En la instalación definitiva sólo cambia el dominio del src. El atributo data-kc-tenant es una clave de enrutado visible en el HTML: no es una credencial y conocerla no autoriza nada.

Qué comprobar desde el móvil

  1. Abrir esta página sin Tailscale, con datos móviles.
  2. Abrir el asistente incrustado y hacer una pregunta real sobre el contenido publicado por AFI.
  3. Comprobar que la respuesta llega con citas y que se puede abrir la fuente.
  4. Navegar la evidencia mientras la respuesta se escribe, y comprobar que no se pierde el hilo.
  5. Cerrar y reabrir: la conversación debe seguir ahí.
  6. Abrir el Hub completo desde el botón de arriba y repetir una pregunta ahí.
  7. Comprobar que esta página funciona con normalidad aunque el asistente falle.

Qué no hay aquí

  • Ninguna consola de administración: no está configurada en esta ejecución.
  • Ninguna ruta de operaciones: no está montada.
  • Ninguna conversación previa: la base de la demo se vació antes de publicar.
  • Ningún dato de las previews estables, que siguen aisladas y sin exposición pública.
